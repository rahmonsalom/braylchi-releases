# Braylchi — o'rnatish fayllari

Braylchi — brayl kitob tayyorlash dasturi: PDF, Word yoki matndan Duxbury DBT (Uzbek Basic) uchun tayyor brayl.

Bu yerda faqat o'rnatish fayllari turadi. Eng so'nggi versiya — **Releases → Latest**:

| Tizim | Fayl |
|---|---|
| Windows | `Braylchi_…_x64-setup.exe` (yoki `.msi`) |
| macOS | `Braylchi_…_universal.dmg` |
| Linux | `Braylchi_…_amd64.AppImage` (yoki `.deb`) |

O'rnatilgan ilova yangi versiya chiqqanda buni o'zi aytadi va rozilik bilan yangilanadi (**Yordam → Yangilanishni tekshirish**). Yangilanishlar imzolangan: ilova faqat Braylchi muallifi imzolagan faylni o'rnatadi.
